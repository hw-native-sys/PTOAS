# 动态连续短写与跨行同步分析

开启 `--enable-vecscope-mem-bar=true` 时，PTOAS 可以在无需用户填写上界或断言的情况下优化部分动态连续短写。
它保留普通循环的语义；不能证明优化成立的输入继续使用保守路径。
该分析依据地址、控制流和指令契约，不按芯片名称启用专用规则。

## 证明范围

连续短写的认证同时检查完整标量地址计算无回绕、内层步长与写入字节数相同、状态链单一且没有中途消费者。
分析只折叠短写内层循环，保留外层行号的仿射系数；事务范围包含实际触及的 32 字节块。
已知绝对基址或同一路径上更早的合法 load 的对齐契约可以证明根地址对齐；缺少证明时扩大事务包络。
未知副作用、不连续写入、真实重叠或不能认证的整数转换均保持保守处理。

Gather 的索引可由常量 lane 和已证明有界的标量行偏移组合而成。分析保留公共标量项，
而非将所有行的范围合成一个巨大区间；索引运算必须在相应位宽内不回绕，部分定义的索引不用于证明。

宽 load 的完整物理读取范围始终保留。例如 `UNPK_B16` 读取 128 字节，不能因为只消费前 32 个 BF16 就缩成 64 字节。
对跨行 WAR，允许使用以下执行顺序证明已有同步足够：

```text
本轮 load L(i) → 依赖其结果的 store D(i) → 本轮必执行的 VST_VLD C(i)
                                                     ↓
下一轮 load X(j) → 依赖 X(j) 的短写 S(j)，其中 j > i
```

`C(i)` 将其之前的 store 排在之后的 vector load 之前，因此 `L(i) < D(i) < X(j) < S(j)`。
两端的 SSA 依赖都必须成立；独立写入不能借此删除 WAR。条件分支内的屏障不作为每行必执行的见证。
同一必执行 RAW 屏障也可覆盖更早 store 到后续行 load 的 RAW；WAW 仍单独分析。
分析阶段保留借助计划屏障消除的同迭代 WAR 和跨迭代 RAW/WAR 义务。冗余消除每尝试删除一个屏障，
都使用排除该候选及先前已删除屏障后的实际计划重新验证全部义务；已有显式屏障也可作为见证。
若原见证被删后仍有其他满足条件的屏障，可以删除；否则必须保留该屏障。
同迭代义务有端点无法映射到候选所在 block 时，当前实现保守保留候选，避免漏检经循环结果传出的依赖。
例如先读 A[i]、写 T[i]、屏障 B1、读 T[i]、写 A[i+1]、屏障 B2、再读 T[i]，
虽然 B1 足以保护两次 T 读取，B2 仍承担 A[i+1] 写入到下一轮读取的 RAW 同步，不能仅按同迭代冗余删除。

## 动态循环的自动版本化

对于运行时上界，编译器尝试用更小的区间重新分析依赖并融合状态链。
例如，`i32` 转成 `index` 后已有整数类型给出的上界，仍可试证能缩小该范围的区间。
仅在同步成本下降时，生成运行时检查与保守回退：

```text
if 0 <= rows <= 编译器证明的边界:
    优化后的原循环
else:
    原循环及其保守同步
```

边界来自重新证明后可以优化的区间，不代表分配容量，也不是对用户输入的假设。
搜索当前限制为 2 到 256 的二次幂，循环体最多 512 个操作，且只接受一条短写链、无结果的顶层循环，
避免无界编译成本和代码膨胀。没有收益时不生成分支；已有显式循环屏障的情况不做版本化。

在 #1764 冻结布局的完整 VF2 中，自动选择的区间是 `0..8`。
优化分支每行保留 maxima→load 和 rounded→gather 两处 `VST_VLD`，四次连续短写共用一条状态链、行内最后仅 flush 一次。
零行不执行短写或 flush。生成的模块同时包含回退分支，因此模块内静态屏障总数不等于优化分支执行的屏障数。

## 使用与证据

用户继续书写普通动态循环，使用原来的自动同步选项即可：

```bash
ptoas kernel.pto --pto-backend=vpto --enable-vecscope-mem-bar=true --emit-vpto -o kernel.mlir
```

架构参数按实际目标选择。显式开启自动同步不等于允许删除用户写入的屏障。

编译回归包含嵌套短写、动态分支及回退、零次循环、重复运行 pass、跨行物理 overread、
独立写入、证明屏障被删的 RAW/WAR、循环结果传出的 WAR、替代显式屏障、
标量 gather 范围、未知索引、位宽回绕和部分索引 mask。公共证明用例覆盖 a3/a5。
完整 VF2 输入由公开 quantize 算法重新生成，并按 issue 的冻结布局绑定指针，不能视为原附件的逐字副本。
模拟器用例核对 packed payload 与 BF16 scale，覆盖 0、1、2、8 行和 9 行保守回退；9 行按程序顺序核对 scratch 复用后的最终字节。

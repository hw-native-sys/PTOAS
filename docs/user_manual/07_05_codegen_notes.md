# 7.5 自动内存规划

## 1. 作用

自动内存规划用于减少用户手工指定本地地址的负担。

在适合的 PTO 层级下，用户可以主要关注 tile 语义，而不必一开始就写出全部本地地址细节。

## 2. 相关参数

这一能力通常与：

- `--pto-level`

直接相关。

如果你的环境中还有独立开关，建议在这里一并列出。

## 3. 默认建议

如果你的目标是先写通、先验证语义，建议优先使用支持自动内存规划的默认路径。

## 4. 什么时候调整

以下场景通常不应继续依赖自动内存规划：

- 需要完全手工控制本地地址
- 程序已经采用显式低层地址写法
- 需要精确表达底层资源安排

## 5. 可观察到的效果

使用自动内存规划时，用户通常会观察到：

- 输入程序更简洁
- 不必显式写出全部本地地址
- 更适合示例、验证和功能开发

## 6. 常见用法

```bash
ptoas input.pto --pto-level=level2 -o output.cpp
```

## 7. 排查建议

如果发现地址相关行为不符合预期，建议：

1. 先检查当前是否仍在适合自动内存规划的层级
2. 再检查输入是否已经混入显式低层地址风格
3. 如果需要完全可控行为，再切换到更低层写法

# 7.1 编译选项总览

## 1. 范围

本章介绍 `ptoas` 中与用户直接相关的常用编译选项。

重点说明：

- 这些选项控制什么用户可见行为
- 默认行为是什么
- 什么时候建议修改
- 遇到问题时如何选择

本章不展开 `ptoas` 内部实现细节，只从使用方式和结果差异的角度说明这些选项。

## 2. 阅读建议

如果你是第一次使用 `ptoas`，建议优先关注：

1. 目标架构选择
2. PTO 层级选择
3. 自动同步相关选项

如果你正在排查编译或结果问题，再看：

- 布局相关选项
- 自动内存规划
- 中间结果观察方式

## 3. 选项总表

下表汇总 `ptoas` 显式提供的主要命令行选项。

说明：

- 这里只列 `ptoas` 自身定义的选项
- 不展开 LLVM / MLIR 通用选项，例如 `--help`、`--version`、`--mlir-print-ir-after`
- 某些选项虽然工具支持，但只适合特定排查场景

| 选项 | 参数 | 默认值 | 作用 |
|---|---|---:|---|
| `<input file>` | 路径 | 无 | 输入的 `.pto` 文件 |
| `-o` | 路径 | `-` | 输出文件名；未指定时通常输出到标准输出 |
| `--pto-arch` | `a3` \| `a5` | `a3` | 指定目标架构 |
| `--pto-level` | `level1` \| `level2` \| `level3` | `level2` | 指定编译层级 |
| `--enable-insert-sync` | 无 | 关闭 | 启用常规自动同步插入 |
| `--enable-inject-barrier-all-sync` | 无 | 关闭 | 启用更保守的同步插入策略 |
| `--enable-graph-sync-solver` | 无 | 关闭 | 启用图求解同步模式 |
| `--graph-sync-solver-event-id-max` | 整数 | `64` | 指定图同步模式可用的 event id 上限 |
| `--disable-infer-layout` | 无 | 关闭 | 关闭静态布局推导 |
| `--emit-addptr-trace` | 无 | 关闭 | 在生成的 C++ 中输出 `addptr` 跟踪注释 |
| `--emit-pto-ir` | 无 | 关闭 | 输出 lowering 后的 PTO ISA，而不是 C++ |

## 4. 选项使用顺序

对大多数用户，建议按下面顺序理解和使用这些选项：

1. 先明确 `--pto-arch`
2. 再确认 `--pto-level`
3. 优先保持默认布局相关行为
4. 按需要开启自动同步
5. 只有在排查问题时，再使用更保守的同步选项或中间结果观察选项

# 7.7 调试与排查

## 1. 作用

这类调试与排查选项用于帮助用户定位输入程序、编译选项和最终输出之间的差异。

## 2. 相关参数

- `--emit-pto-ir`

如果你的环境中还有其他观察类参数，建议在这里继续补充。

## 3. 默认建议

日常使用不一定需要开启。

只有在排查问题、比较不同选项效果，或者确认输入语义是否已经表达清楚时，才建议使用。

## 4. 什么时候调整

建议在以下场景使用：

- 输出结果不符合预期
- 想确认问题出在输入还是输出阶段
- 想比较不同编译选项造成的差异

## 5. 可观察到的效果

开启后，用户可以更直接地看到：

- 当前程序的结构化表示
- 某些类型、布局或同步信息是否已经明确
- 不同选项下结果是否发生变化

## 6. 常见用法

```bash
ptoas input.pto --emit-pto-ir
```

```bash
ptoas input.pto --enable-insert-sync --emit-pto-ir
```

## 7. 排查建议

建议把它作为对比工具使用：

1. 先看默认结果
2. 再只改一个选项重新观察
3. 不要一次同时修改多个开关

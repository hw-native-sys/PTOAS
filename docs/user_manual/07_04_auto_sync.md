# 7.4 布局相关选项

## 1. 作用

布局相关选项用于控制编译器是否自动解释或补全部分布局信息。

它主要影响 view、搬运和部分计算路径对布局的理解方式。

## 2. 相关参数

- `--disable-infer-layout`

建议在这里明确写出默认行为，例如默认开启布局相关处理，只有显式关闭时才停用。

## 3. 默认建议

大多数场景建议保持默认，不要关闭。

## 4. 什么时候调整

只有在以下场景，才建议临时关闭：

- 怀疑问题与布局解释方式有关
- 想比较不同布局处理方式下的结果差异
- 正在做最小化排查

## 5. 可观察到的效果

调整该选项后，用户可能观察到：

- 某些布局相关问题更早暴露
- 中间结果中的布局信息表现不同
- 某些搬运或转换路径的结果不同

## 6. 常见用法

```bash
ptoas input.pto -o output.cpp
```

```bash
ptoas input.pto --disable-infer-layout -o output.cpp
```

## 7. 排查建议

如果怀疑问题与布局有关，建议：

1. 先检查 `shape`、`strides` 和 view 构造是否合理
2. 再比较默认行为和关闭该选项时的差异
3. 最后再检查后续操作是否与当前布局匹配

# 7.3 PTO 层级选项

## 1. 作用

PTO 层级选项用于控制输入程序采用哪一层 PTO 表达方式。

不同层级的主要差别在于：由用户显式写出的资源细节有多少，以及编译器是否继续补充部分信息。

## 2. 相关参数

- `--pto-level=level2`
- `--pto-level=level3`

如果你的使用环境有默认值，建议在这里补充默认行为。

## 3. 默认建议

大多数用户建议优先使用：

```bash
--pto-level=level2
```

这是更适合常规 `.pto` 编写、示例开发和功能验证的层级。

## 4. 什么时候调整

建议在以下场景考虑切换到 `level3`：

- 需要显式控制本地地址
- 需要更低层的资源和同步表达
- 当前程序已经采用低层显式写法

## 5. 可观察到的效果

选择不同层级后，用户通常会观察到：

- 输入程序对显式地址的要求不同
- 某些低层写法只适用于特定层级
- 自动补全能力的适用范围不同

## 6. 常见用法

```bash
ptoas input.pto --pto-level=level2 -o output.cpp
```

```bash
ptoas input.pto --pto-level=level3 -o output.cpp
```

## 7. 排查建议

如果你遇到地址相关报错或层级不匹配问题，建议：

1. 先确认当前 `.pto` 的写法更接近 `level2` 还是 `level3`
2. 再检查是否混用了高层和低层风格
3. 如果只是想先跑通样例，优先回到 `level2`

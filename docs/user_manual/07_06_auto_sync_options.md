# 7.6 自动同步选项

## 1. 作用

自动同步选项用于减少用户手工插入同步操作的负担。

它主要影响编译输出中同步相关行为的处理方式。

## 2. 相关参数

- `--enable-insert-sync`
- `--enable-inject-barrier-all-sync`

建议在这里明确写出默认行为以及这两个选项的互斥关系。

## 3. 默认建议

如果你希望先快速跑通常规场景，建议优先尝试：

```bash
--enable-insert-sync
```

如果只是普通示例验证，也可以先保持默认，再按需要开启。

## 4. 什么时候调整

建议在以下场景调整自动同步选项：

- 不想一开始手工写同步
- 怀疑问题与同步不足有关
- 需要用更保守的方式做排障

## 5. 可观察到的效果

切换同步模式后，用户通常会观察到：

- 同步相关错误表现不同
- 某些程序在一种模式下可通过、另一种模式下行为不同
- 更保守的模式更适合确认问题是否与同步有关

## 6. 常见用法

```bash
ptoas input.pto --enable-insert-sync -o output.cpp
```

```bash
ptoas input.pto --enable-inject-barrier-all-sync -o output.cpp
```

## 7. 排查建议

如果怀疑问题与同步有关，建议：

1. 先尝试常规自动同步
2. 如果问题仍存在，再切换到更保守模式
3. 再回头检查程序中的 producer-consumer 关系是否表达清楚

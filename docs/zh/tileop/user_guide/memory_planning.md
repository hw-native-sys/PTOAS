# 自动内存规划

## 作用

自动内存规划是 `ptoas` 编译流程的一部分，用于减少用户手工指定本地地址的负担：编译器会依据 Tile 的地址空间、大小、对齐和使用区间分配本地偏移，并在不改变程序语义的前提下复用存储。

使用自动内存规划时，用户可以主要关注 Tile 语义，无需显式指定全部本地地址。

## 相关参数

自动内存规划由 `--enable-plan-memory` 控制，**默认开启**，当前版本**不支持关闭**：编译流程会为没有显式地址的 `pto.alloc_tile` 规划地址。

- `--enable-plan-memory`
  自动内存规划总开关，当前只接受开启。

- `--plan-memory-order-by-size`
  默认关闭，只影响同一地址空间内的规划顺序：关闭时按 Tile 的**声明顺序**（`pto.alloc_tile` 在源程序中的先后）依次规划；开启后 `ptoas` 会在同一地址空间内优先规划较大的本地 buffer，再应用基础的内存复用策略。

## 默认建议

如果需要优先验证程序语义，可以使用默认的自动内存规划方式。

## 可观察到的效果

使用自动内存规划时，通常可以：

- 减少显式本地地址配置。
- 简化输入程序。
- 降低示例和功能验证阶段的地址配置复杂度。

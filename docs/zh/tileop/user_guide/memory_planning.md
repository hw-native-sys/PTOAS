# 自动内存规划

## 作用

自动内存规划用于减少用户手工指定本地地址的负担。

使用自动内存规划时，用户可以主要关注Tile语义，而无需显式指定全部本地地址。

## 相关参数

自动内存规划支持以下参数：

- `--plan-memory-order-by-size`

启用后，PTOAS会在同一AddressSpace内优先规划较大的本地buffer，再应用基础的内存复用策略。

该选项默认关闭。

## 默认建议

如果需要优先验证程序语义，可以使用默认的自动内存规划方式。

## 什么时候调整

以下场景通常不适合继续依赖自动内存规划：

- 需要完全手工控制本地地址。
- 程序已经显式指定本地地址。
- 需要精确控制底层资源分配。

## 可观察到的效果

使用自动内存规划时，通常可以：

- 减少显式本地地址配置。
- 简化输入程序。
- 降低示例和功能验证阶段的地址配置复杂度。

## 排查建议

如果发现地址相关行为不符合预期，建议：

1. 检查当前是否启用了自动内存规划。
2. 检查输入中是否已经显式指定本地地址。
3. 如果需要完全控制本地地址，请改用显式地址配置方式。
